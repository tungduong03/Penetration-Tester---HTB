# Windows Remote Management Protocols

Windows hỗ trợ quản trị từ xa thông qua 3 giao thức chính:

| Giao thức | Chức năng | Port mặc định |
|---|---|---|
| RDP (Remote Desktop Protocol) | Điều khiển máy tính qua giao diện GUI | TCP/UDP 3389 |
| WinRM (Windows Remote Management) | Quản trị từ xa qua command line/PowerShell | TCP 5985 (HTTP), 5986 (HTTPS) |
| WMI (Windows Management Instrumentation) | Đọc, sửa cấu hình và quản trị hệ thống Windows | TCP 135, sau đó chuyển sang port động |

---

## 1. RDP

- Giao thức của Microsoft cho phép truy cập và điều khiển máy Windows từ xa qua GUI.
- Sử dụng TCP/UDP port 3389.
- Hỗ trợ mã hóa TLS/SSL; một số hệ thống có thể cho phép cơ chế bảo mật yếu hơn.
- NLA (Network Level Authentication) yêu cầu xác thực trước khi thiết lập phiên desktop.
- Chứng chỉ tự ký mặc định có thể gây cảnh báo khi xác minh danh tính máy chủ.

### Footprinting RDP

**Nmap:**
```bash
nmap -sV -sC -p3389 --script rdp* <IP>
```

Có thể thu thập:
- Trạng thái port và phiên bản dịch vụ.
- NLA và các cơ chế bảo mật được hỗ trợ.
- Tên máy tính, tên miền NetBIOS và phiên bản hệ điều hành.

**Theo dõi gói tin:**
```bash
nmap -sV -sC -p3389 --packet-trace --disable-arp-ping -n <IP>
```

Lưu ý: RDP cookie `mstshash=nmap` có thể bị hệ thống giám sát hoặc EDR phát hiện.

**Kiểm tra cấu hình bảo mật RDP:**
```bash
git clone https://github.com/CiscoCXSecurity/rdp-sec-check.git
cd rdp-sec-check
./rdp-sec-check.pl <IP>
```

Cài thư viện Perl cần thiết nếu thiếu:
```bash
sudo cpan
```

Trong CPAN:
```text
install Encoding::BER
```

**Kết nối RDP từ Linux:**
```bash
xfreerdp /u:<USER> /p:'<PASSWORD>' /v:<IP>
```

Các công cụ khác: `rdesktop`, `Remmina`.

## 2. WinRM

- Giao thức quản trị Windows từ xa dựa trên WS-Management và SOAP.
- Cho phép thực thi lệnh từ xa thông qua Windows Remote Shell (WinRS) và PowerShell.
- Thường được bật mặc định trên Windows Server 2012 trở lên; Windows 10 cần bật và cấu hình rõ ràng.
- TCP 5985 sử dụng HTTP; TCP 5986 sử dụng HTTPS.

### Footprinting WinRM

**Nmap:**
```bash
nmap -sV -sC -p5985,5986 --disable-arp-ping -n <IP>
```

**Kiểm tra từ PowerShell:**
```powershell
Test-WsMan <HOST>
```

**Kết nối từ Kali Linux bằng Evil-WinRM:**
```bash
evil-winrm -i <IP> -u <USER> -p '<PASSWORD>'
```

Nếu xác thực thành công, có thể sử dụng shell PowerShell trên máy đích theo quyền của tài khoản.

## 3. WMI

- WMI là công nghệ quản trị của Microsoft, dựa trên CIM/WBEM.
- Cho phép đọc và sửa nhiều thiết lập của hệ thống Windows.
- Có thể được sử dụng thông qua PowerShell, VBScript và WMIC.
- Kết nối ban đầu qua TCP 135, sau đó sử dụng một port động để giao tiếp tiếp theo.

### Footprinting và thực thi lệnh WMI

Sử dụng `wmiexec.py` thuộc bộ công cụ Impacket:

```bash
/usr/share/doc/python3-impacket/examples/wmiexec.py <DOMAIN>/<USER>:'<PASSWORD>'@<IP> "hostname"
```

Ví dụ kết quả:
```text
ILF-SQL-01
```

Lệnh trên thực thi `hostname` trên máy đích và trả về tên máy tính nếu xác thực thành công.

---

## 4. Quy trình kiểm tra nhanh

1. Quét các port thường gặp:
   ```bash
   nmap -sV -p3389,5985,5986,135 <IP>
   ```
2. Nếu phát hiện RDP, kiểm tra NLA, phiên bản và cấu hình mã hóa.
3. Nếu phát hiện WinRM, kiểm tra khả năng truy cập và xác thực bằng Evil-WinRM.
4. Nếu có WMI, kiểm tra TCP 135 và khả năng thực thi lệnh bằng Impacket khi có thông tin xác thực hợp lệ.
5. Đối chiếu kết quả với quyền tài khoản và cấu hình thực tế của máy đích.

**Lưu ý:** Port mở không đồng nghĩa với việc có thể đăng nhập hoặc thực thi lệnh. Chỉ kiểm tra trên hệ thống được phép.
