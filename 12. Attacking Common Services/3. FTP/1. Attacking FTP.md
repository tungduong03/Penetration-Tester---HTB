# Tấn công FTP (Attacking FTP) — Tóm tắt

## Tổng quan

FTP (File Transfer Protocol) là giao thức mạng chuẩn dùng để truyền file giữa các máy tính, đồng thời hỗ trợ các thao tác thư mục như liệt kê, đổi tên, xóa file/thư mục. FTP mặc định lắng nghe trên **cổng TCP/21**.

Để tấn công FTP Server, ta có thể khai thác cấu hình sai, quyền hạn quá mức, lỗ hổng đã biết hoặc phát hiện lỗ hổng mới. Sau khi truy cập được, cần tìm kiếm thông tin nhạy cảm trong các thư mục.

---

## 1. Thu thập thông tin (Enumeration)

Sử dụng **Nmap** với script mặc định (`-sC`) và phát hiện phiên bản (`-sV`) để kiểm tra FTP:

```bash
sudo nmap -sC -sV -p 21 192.168.2.142
```

Script `ftp-anon` tự động kiểm tra xem FTP có cho phép **đăng nhập ẩn danh** hay không. Cờ `-sV` cung cấp banner FTP, thường chứa tên và phiên bản phần mềm.

Ngoài ra có thể dùng **ftp client** hoặc **nc** (netcat) để tương tác trực tiếp với dịch vụ FTP.

---

## 2. Cấu hình sai (Misconfigurations)

### Xác thực ẩn danh (Anonymous Authentication)

FTP có thể được cấu hình cho phép đăng nhập ẩn danh với username `anonymous` và không cần mật khẩu:

```bash
ftp 192.168.2.142
# Username: anonymous
# Password: (để trống)
```

**Nguy hiểm khi:**
- Quyền đọc/ghi không được thiết lập đúng.
- Thư mục chứa thông tin nhạy cảm mà người dùng ẩn danh có thể truy cập.
- Kẻ tấn công có thể tải xuống dữ liệu nhạy cảm hoặc upload script độc hại.
- Kết hợp với lỗ hổng khác (ví dụ: path traversal trên web) để thực thi mã.

### Các lệnh FTP cơ bản

| Lệnh | Chức năng |
|------|-----------|
| `ls` | Liệt kê file và thư mục |
| `cd` | Chuyển thư mục |
| `get` | Tải xuống một file |
| `mget` | Tải xuống nhiều file |
| `put` | Upload một file |
| `mput` | Upload nhiều file |
| `help` | Xem trợ giúp |

## 3. Tấn công theo giao thức (Protocol Specifics Attacks)

### 3.1. Brute Force (Dò mật khẩu)

Khi không có xác thực ẩn danh, ta có thể dò mật khẩu bằng danh sách username/password. Công cụ phổ biến: **Medusa**.

```bash
medusa -u fiona -P /usr/share/wordlists/rockyou.txt -h 10.129.203.7 -M ftp
```

| Tùy chọn | Mô tả |
|-----------|-------|
| `-u` | Chỉ định một username |
| `-U` | File chứa danh sách username |
| `-P` | File chứa danh sách password |
| `-M` | Giao thức mục tiêu (ftp) |
| `-h` | IP hoặc hostname mục tiêu |

> **Lưu ý:** Hầu hết ứng dụng hiện đại đã có cơ chế chống brute force. Phương pháp hiệu quả hơn là **Password Spraying** (thử một mật khẩu phổ biến cho nhiều tài khoản).

### 3.2. FTP Bounce Attack

FTP Bounce Attack lợi dụng máy chủ FTP làm trung gian để gửi lưu lượng đến một thiết bị khác trong cùng mạng. Kẻ tấn công sử dụng lệnh `PORT` để đánh lừa kết nối FTP thực thi lệnh và thu thập thông tin từ thiết bị không tiếp xúc trực tiếp với internet.

**Kịch bản:**
- `FTP_DMZ` — máy chủ FTP tiếp xúc internet.
- `Internal_DMZ` — thiết bị nội bộ không tiếp xúc internet.
- Kẻ tấn công dùng kết nối đến `FTP_DMZ` để quét cổng trên `Internal_DMZ`.

Thực hiện bằng Nmap với cờ `-b`:

```bash
nmap -Pn -v -n -p80 -b anonymous:password@10.10.110.213 172.17.0.2
```

> **Lưu ý:** Các máy chủ FTP hiện đại đã có cơ chế bảo vệ mặc định chống lại kiểu tấn công này, nhưng nếu cấu hình sai, server vẫn có thể bị khai thác.

## Tóm tắt các phương pháp tấn công FTP

| Phương pháp | Mục đích | Công cụ |
|-------------|----------|---------|
| **Enumeration** | Thu thập banner, phát hiện anonymous login | Nmap (`-sC -sV`), ftp client, nc |
| **Anonymous Login** | Truy cập không cần xác thực | ftp client |
| **Brute Force** | Dò tìm mật khẩu | Medusa, Hydra |
| **FTP Bounce** | Quét mạng nội bộ qua FTP trung gian | Nmap (`-b`) |
