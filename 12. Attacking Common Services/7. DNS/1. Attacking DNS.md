# Tấn công DNS (Attacking DNS) — Tóm tắt đầy đủ

## Tổng quan

**DNS (Domain Name System)** chuyển đổi tên miền (ví dụ: hackthebox.com) thành địa chỉ IP số (ví dụ: 104.17.42.72). DNS chủ yếu dùng **UDP/53**, nhưng sử dụng **TCP/53** khi gói tin quá lớn cho một gói UDP đơn lẻ. Vì hầu hết mọi ứng dụng mạng đều sử dụng DNS, các cuộc tấn công nhắm vào DNS server là một trong những mối đe dọa phổ biến và nghiêm trọng nhất hiện nay.

---

## 1. Thu thập thông tin (Enumeration)

DNS chứa nhiều thông tin giá trị về tổ chức: cách vận hành, dịch vụ cung cấp, nhà cung cấp bên thứ ba.

```bash
nmap -p53 -Pn -sV -sC 10.10.110.213
```

Kết quả cho thấy phiên bản DNS server (ví dụ: ISC BIND 9.11.3).

---

## 2. DNS Zone Transfer

### Khái niệm

**DNS Zone** là phần của namespace DNS được quản lý bởi tổ chức hoặc quản trị viên cụ thể. **DNS Zone Transfer** là quá trình sao chép một phần database DNS từ server này sang server khác.

**Lỗ hổng:** Zone transfer **không yêu cầu xác thực**. Nếu DNS server không được cấu hình đúng (không giới hạn IP được phép thực hiện zone transfer), bất kỳ ai đều có thể yêu cầu bản sao thông tin zone.

> Zone transfer dùng **TCP** thay vì UDP để đảm bảo truyền dữ liệu tin cậy.

### Khai thác bằng dig

```bash
dig AXFR @ns1.inlanefreight.htb inlanefreight.htb
```

Kết quả trả về toàn bộ bản ghi DNS: SOA, NS, A, AAAA... bao gồm các subdomain nội bộ như `admin`, `hr`, `support` và IP tương ứng.

### Khai thác bằng Fierce

```bash
fierce --domain zonetransfer.me
```

Fierce tự động liệt kê tất cả DNS server của domain gốc và quét zone transfer, trả về toàn bộ bản ghi bao gồm A, MX, TXT, CNAME, SRV, LOC...

## 3. Domain Takeover & Subdomain Enumeration

### Domain Takeover

**Domain takeover** là việc đăng ký tên miền đã hết hạn để chiếm quyền kiểm soát domain khác, từ đó:

- Lưu trữ nội dung độc hại trên website
- Gửi email phishing sử dụng domain đã chiếm

### Subdomain Takeover

Xảy ra khi bản ghi **CNAME** trỏ đến domain bên thứ ba đã hết hạn:

```
sub.target.com.   60   IN   CNAME   anotherdomain.com
```

Nếu `anotherdomain.com` hết hạn → bất kỳ ai đăng ký domain đó sẽ kiểm soát hoàn toàn `sub.target.com`.

### Subdomain Enumeration

#### Subfinder — thu thập từ nguồn mở

```bash
./subfinder -d inlanefreight.com -v
```

Thu thập subdomain từ các nguồn như DNSdumpster, AlienVault, BufferOver...

#### Subbrute — brute force DNS nội bộ

```bash
git clone https://github.com/TheRook/subbrute.git
cd subbrute
echo "ns1.inlanefreight.com" > ./resolvers.txt
./subbrute.py inlanefreight.com -s ./names.txt -r ./resolvers.txt
```

Ưu điểm: cho phép dùng resolver tự định nghĩa, phù hợp cho kiểm thử nội bộ trên host không có internet.

### Kiểm tra CNAME và xác nhận lỗ hổng

```bash
host support.inlanefreight.com
# Kết quả: alias for inlanefreight.s3.amazonaws.com
```

Nếu truy cập URL hiển thị lỗi **NoSuchBucket** → subdomain có thể bị takeover bằng cách tạo S3 bucket cùng tên.

> Tham khảo repository **can-i-take-over-xyz** để kiểm tra dịch vụ nào dễ bị subdomain takeover.

## 4. DNS Spoofing (DNS Cache Poisoning)

### Khái niệm

**DNS Spoofing** là thay đổi bản ghi DNS hợp lệ bằng thông tin giả để chuyển hướng lưu lượng đến website lừa đảo.

### Các đường tấn công

- **Man-in-the-Middle (MITM):** Chặn giao tiếp giữa người dùng và DNS server để chuyển hướng đến đích giả.
- **Khai thác lỗ hổng DNS server:** Chiếm quyền server để sửa đổi bản ghi DNS.

### Local DNS Cache Poisoning bằng Ettercap

**Bước 1 — Cấu hình file DNS giả:**

```bash
# /etc/ettercap/etter.dns
inlanefreight.com      A   192.168.225.110
*.inlanefreight.com    A   192.168.225.110
```

Map tên miền mục tiêu đến IP của kẻ tấn công.

**Bước 2 — Khởi động Ettercap và quét host:**

- Vào `Hosts > Scan for Hosts`
- Thêm IP máy nạn nhân vào Target1
- Thêm IP default gateway vào Target2

**Bước 3 — Kích hoạt dns_spoof:**

- Vào `Plugins > Manage Plugins` → chọn `dns_spoof`
- Ettercap gửi phản hồi DNS giả đến máy nạn nhân

**Kết quả:**

- Khi nạn nhân truy cập `inlanefreight.com` → bị chuyển hướng đến trang giả trên IP 192.168.225.110.
- Lệnh `ping inlanefreight.com` cũng phân giải đến IP kẻ tấn công.

> Công cụ thay thế: **Bettercap** cũng hỗ trợ DNS spoofing MITM.

## Tóm tắt các phương pháp tấn công DNS

| Phương pháp | Công cụ | Mục đích |
|-------------|---------|----------|
| **Enumeration** | Nmap | Phát hiện DNS server, phiên bản |
| **Zone Transfer** | dig (`AXFR`), Fierce | Dump toàn bộ namespace DNS |
| **Subdomain Enumeration** | Subfinder, Subbrute, Sublist3r | Liệt kê subdomain |
| **Subdomain Takeover** | host, nslookup, can-i-take-over-xyz | Chiếm subdomain trỏ CNAME đến domain hết hạn |
| **DNS Spoofing** | Ettercap, Bettercap | Chuyển hướng lưu lượng bằng phản hồi DNS giả |
